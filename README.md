# 深澜校园网无感登录（Srun Auto Login）

开机进桌面的那一刻，校园网已经是通的——不需要打开浏览器手动认证。

北京理工大学有线网实测：开机 **+26.0 秒**完成认证，**早于进桌面（+26.1 秒）**。

> 默认配置为北京理工大学（门户 `http://10.0.0.55`，`ac_id=43`）。
> 其他学校只要认证系统同为**深澜（Srun）**，改一下配置就能用，见[其他学校适配](#其他学校适配同为深澜)。

---

## 它是怎么工作的

1. **开机早期**，Windows 服务（`SRunAutoLogin`，LocalSystem 身份）被服务控制管理器（SCM）直接拉起
   ——和壁纸软件「用户还没登录就已经准备好」是同一机制，比任务计划程序早得多
2. 服务等待网络栈就绪（2 秒轮询，最长 180 秒），然后做四道环境判定：
   **有路由到门户 → 出口网卡在登录模式内 → 对端确认是深澜门户 → 当前未联网**，任何一道不过就跳过
3. 判定需要登录时，按门户自己的 JS 逆向出的协议完成认证（challenge → HMAC-MD5 / xEncode / 自定义 base64 / chksum → login）
4. 默认认证成功后服务**自动退出**（不常驻）；可选开启**断线自动重连**：
   服务常驻守护（30 秒周期），掉线自动恢复登录，配置改动实时生效

> **登录模式**可配置：仅有线（默认）/ 仅无线 / 有线+无线都登录；
> **断线自动重连**可选开关。都在 `深澜配置.bat` 里改，立即生效。

> 为什么用服务而不是计划任务：实测计划任务开机 +37s 才触发、+54s 才认证完，
> 站在登录界面看到的一直是断网；服务由 SCM 早期拉起，认证完成时刻提前了 28 秒，
> 追到进桌面之前。

## 快速开始

### 环境要求

- Windows 10/11
- **Python 3.8+**（安装时勾选 `Add python.exe to PATH`）
- 零第三方 Python 包，全部标准库，不用 `pip install`
- PowerShell 7 仅为可选（只影响登录后网络图标是否立即刷新，安装服务不再需要它）

### 步骤

1. 把**整个文件夹**复制到电脑上任意位置（路径无关，脚本自定位）
2. 双击 **`深澜配置.bat`**：填学号 / 密码（`ac_id`、门户地址直接回车用默认；
   无线用户把登录模式改成「仅无线」或「有线+无线」）
3. 双击 **`深澜测试.bat`**：确认判定正确，可选 1 做一次登录测试
4. 双击 **`深澜服务管理.bat`** → 选 1 安装 → UAC 点「是」→
   **装完立即启动跑一次验证，无需重启**，结果直接显示在窗口里
5. （推荐）重启一次，体验「进桌面网络已通」

> 用 git 克隆本仓库的话，`config.json` 不会跟过来（在 `.gitignore` 里），
> 第 2 步填一次就有了。

## 三个双击脚本

| 脚本 | 用途 |
|---|---|
| `深澜配置.bat` | 配置中心：账号密码 / ac_id / 门户地址 / 登录模式 / 断线自动重连 |
| `深澜测试.bat` | 测试台：显示当前判定，菜单执行登录测试 / 注销（可安全重复执行） |
| `深澜服务管理.bat` | 服务管理：显示核心服务状态，菜单安装 / 卸载（需要 UAC） |

所有脚本都是菜单式的：打开先显示当前状态，按数字选择操作，直接回车退出。

## 常用命令

```bat
python src\srun_login.py doctor      :: 环境体检（排障先跑这个）
python src\srun_login.py status      :: 打印当前环境判定（含登录模式）
python src\srun_login.py config      :: 配置菜单（等价于 深澜配置.bat）
python src\srun_login.py lab         :: 测试台（等价于 深澜测试.bat）
python src\srun_login.py service     :: 服务管理（等价于 深澜服务管理.bat）
python src\srun_login.py svc-status  :: 服务状态 + 最近日志
python src\srun_login.py once        :: 手动跑一次认证（认证流程与服务相同）
python src\srun_login.py test        :: 逐步诊断 + 完整认证
```

退出码：`0` 成功 · `1` 失败 · `2` 配置错误 · `3` 按设计跳过 · `10` 已请求提权

## 其他学校适配（同为深澜）

如果你的学校认证页面也是深澜（Srun）系统——特征是认证页 URL 含 `srun_portal`，
或页面底部有「srun」字样——那么**不需要改任何代码**：

**双击 `深澜配置.bat` 选 [2]**，改两项即可：

- **门户地址**：连上校园网（先不认证），浏览器随便打开一个 `http://` 网站，
  会被强制重定向到认证页——重定向后的地址栏就是门户地址，
  例如 `http://10.248.98.2/srun_portal_pc?ac_id=5&theme=pro` 里填 `http://10.248.98.2`
- **ac_id**：同一个 URL 里的 `?ac_id=5`，填 `"5"`（**字符串，不是整数**）
- 拿不准就 F12 打开网络面板，点一次登录按钮，看 `srun_portal` 请求里的参数

也可以直接编辑 `config.json`：

```json
{
  "username": "你的账号",
  "password": "你的密码",
  "ac_id": "5",
  "portal": "http://10.248.98.2",
  "login_mode": "wired"
}
```

改完双击 `深澜测试.bat` 选 1 验证：

- 登录成功 → 适配完成
- 返回 `chksum error` → 对方门户的前端 JS 与本仓库逆向的版本有差异，
  参照 [项目文档.md](项目文档.md) 第 8 节的方法，从对方门户重新抠 JS 对拍

> 仅适用于深澜系统。锐捷 / Dr.COM 等需要重做整个协议层。

## 常见问题

| 现象 | 处理 |
|---|---|
| `[ERROR] Python not found` | 重装 Python，勾选 `Add python.exe to PATH` |
| 判定「出口是无线网卡…当前登录模式为仅有线，跳过」 | 双击 `深澜配置.bat` 选 3，把登录模式改成「仅无线」或「有线+无线」 |
| 判定「不可达 / 不是深澜门户」 | 不在校园网或网线没插，正常跳过 |
| 返回 `password error` | 双击 `深澜配置.bat` 重填密码 |
| 开机没自动登录 | 双击 `深澜服务管理.bat` 看服务状态；挪动过项目文件夹就重装一次（服务记录的是绝对路径） |
| 服务报 1053 超时 | 已配 60 秒自动重启自愈；频繁出现可给 Python 目录加杀毒软件白名单 |

更多排障见 [项目文档.md](项目文档.md) 第 5 节。

## 日志与隐私

- 服务日志：`logs\srun-svc.log`（超过 1MB 自动轮转，磁盘占用上限约 2MB）
- 启动探针：`logs\entry.log`（每次进程启动一行，超过 32KB 重建）
- **`config.json` 里是明文密码**，已被 `.gitignore` 排除不会入库；
  但目录如果走网盘同步 / 发给别人，记得先删掉它，让对方自己填
