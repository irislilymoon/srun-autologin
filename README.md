# 深澜校园网无感登录（Srun Auto Login）

开机进桌面的那一刻，校园网已经是通的——不需要打开浏览器手动认证。

北京理工大学有线网实测：开机 **+26.0 秒**完成认证，**早于进桌面（+26.1 秒）**。

> 默认配置为北京理工大学（门户 `http://10.0.0.55`，`ac_id=43`）。
> 其他学校只要认证系统同为**深澜（Srun）**，改一下配置就能用，见[其他学校适配](#其他学校适配同为深澜)。

---

## 它是怎么工作的

1. **开机早期**，Windows 服务（`SRunAutoLogin`，LocalSystem 身份）被服务控制管理器（SCM）直接拉起
   ——和壁纸软件「用户还没登录就已经准备好」是同一机制，比任务计划程序早得多
2. 服务等待网络栈就绪（2 秒轮询，最长 180 秒），然后做四道环境判定：
   **有路由到门户 → 出口是有线网卡 → 对端确认是深澜门户 → 当前未联网**，任何一道不过就跳过
3. 判定需要登录时，按门户自己的 JS 逆向出的协议完成认证（challenge → HMAC-MD5 / xEncode / 自定义 base64 / chksum → login）
4. 认证成功、刷新网络图标后，服务上报完成并**自动退出**——不常驻、不重连、不占后台

> 为什么不用计划任务：实测 SYSTEM 计划任务开机 +37s 才触发、+54s 才认证完，
> 站在登录界面看到的一直是断网。改成服务后认证完成时刻提前了 28 秒，追到进桌面之前。
> 完整对比见 [项目文档.md](项目文档.md) 1.3 节。

## 快速开始

### 环境要求

- Windows 10/11
- **Python 3.8+**（安装时勾选 `Add python.exe to PATH`）
- **PowerShell 7**（仅「安装开机自启」用到，https://aka.ms/powershell ）
- 零第三方 Python 包，全部标准库，不用 `pip install`

### 步骤

1. 把**整个文件夹**复制到电脑上任意位置（路径无关，脚本自定位）
2. 双击 **`配置账号密码.bat`**，填学号 / 密码（`ac_id`、门户地址直接回车用默认）
3. 双击 **`深澜网络状态.bat`**，应显示：

   ```
   出口网卡 : 以太网
   校园门户 : 已确认
   判定     : login / skip（视当前是否已联网）
   ```

4. 双击 **`深澜登录测试.bat`** 验证认证流程（可先双击 `深澜注销-测试用.bat` 制造未认证状态）
5. 双击 **`安装开机自启.bat`** → UAC 点「是」→ 装的是 Windows 服务，
   **装完立即启动跑一次验证，无需重启**，窗口里直接看到结果
6. （推荐）重启一次，体验「进桌面网络已通」

> 用 git 克隆本仓库的话，`config.json` 不会跟过来（在 `.gitignore` 里），
> 第 2 步填一次就有了。

## 日常使用

### 六个双击脚本

| 脚本 | 用途 |
|---|---|
| `配置账号密码.bat` | 改用户名 / 密码 / ac_id / 门户地址 |
| `深澜网络状态.bat` | 「为什么没自动登录？」→ 先跑这个 |
| `深澜登录测试.bat` | 断网后验证能否自动恢复 |
| `深澜注销-测试用.bat` | 注销会话，制造「未认证」状态用于测试 |
| `安装开机自启.bat` / `卸载开机自启.bat` | 装 / 卸 Windows 服务（需要 UAC） |

### 常用命令

```bat
python srun_login.py doctor      :: 环境体检（排障先跑这个）
python srun_login.py status      :: 打印当前环境判定
python srun_login.py svc-status  :: 服务状态 + 最近日志
python srun_login.py once        :: 手动跑一次认证（与服务同一段逻辑）
python srun_login.py test        :: 逐步诊断 + 完整认证
python srun_login.py logout      :: 注销会话
python srun_login.py watch       :: 常驻守护（默认不装，可选）
```

退出码：`0` 成功 · `1` 失败 · `2` 配置错误 · `3` 按设计跳过 · `10` 已请求提权

## 其他学校适配（同为深澜）

如果你的学校认证页面也是深澜（Srun）系统——特征是认证页 URL 含 `srun_portal`，
或页面底部有「srun」字样——那么**不需要改任何代码**，改 `config.json` 即可：

```json
{
  "username": "你的账号",
  "password": "你的密码",
  "ac_id": "改成你学校的",
  "portal": "http://改成你学校的门户地址"
}
```

**怎么找到你学校的 `portal` 和 `ac_id`**：

1. 连上校园网（先不认证），浏览器随便打开一个 `http://` 网站，会被强制重定向到认证页
2. 重定向后的地址栏就是门户地址，例如 `http://10.248.98.2/srun_portal_pc?ac_id=5&theme=pro`
   —— `portal` 填 `http://10.248.98.2`，`ac_id` 填 `"5"`（**字符串，不是整数**）
3. 拿不准就 F12 打开网络面板，点一次登录按钮，看 `srun_portal` 请求里的参数

改完依次跑 `深澜网络状态.bat` → `深澜登录测试.bat` 验证：

- 「校园门户: 已确认」+ 登录成功 → 适配完成
- 返回 `chksum error` → 说明对方门户的前端 JS 与本仓库逆向的版本有差异，
  参照 [项目文档.md](项目文档.md) 第 8 节的方法，从对方门户重新抠 JS 对拍

> 仅适用于深澜系统。锐捷 / Dr.COM 等需要重做整个协议层。

## 常见问题

| 现象 | 处理 |
|---|---|
| `[ERROR] Python not found` | 重装 Python，勾选 `Add python.exe to PATH` |
| 判定「出口是无线网卡…跳过」 | 正常，自动登录仅限有线；插网线即可 |
| 判定「不可达 / 不是深澜门户」 | 不在校园网或网线没插，正常跳过 |
| 返回 `password error` | 双击 `配置账号密码.bat` 重填 |
| 开机没自动登录 | 跑 `python srun_login.py svc-status`；挪动过项目文件夹就重跑一次 `安装开机自启.bat`（服务记录的是绝对路径） |
| 服务报 1053 超时 | 已配 60 秒自动重启自愈；频繁出现可给 Python 目录加杀毒软件白名单 |

更多排障见 [项目文档.md](项目文档.md) 第 5 节。

## 日志与隐私

- 服务日志：`logs\srun-svc.log`（超过 1MB 自动轮转，磁盘占用上限约 2MB）
- 启动探针：`logs\entry.log`（每次进程启动一行，超过 32KB 重建）
- **`config.json` 里是明文密码**，已被 `.gitignore` 排除不会入库；
  但目录如果走网盘同步 / 发给别人，记得先删掉它，让对方自己填
